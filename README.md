# 网络调试助手 Android V2.0.2

这是一个手机端网络调试助手，用 Android 原生 Java 实现，目标是在手机上覆盖 `netassist5.15.exe` 常用功能。

## 当前功能

- TCP Server：选择手机本地主机地址和端口监听，默认 `0.0.0.0` 表示所有网卡，也可选择手机 WiFi IP。
- TCP Client：连接远端 IP/端口后收发数据。
- UDP：选择本机 IP/端口，向远端 IP/端口发送数据并接收 UDP 数据。
- 接收设置：ASCII/HEX 显示、日志模式、自动换行、不显示、保存到文件。
- 发送设置：ASCII/HEX 发送、自动解析转义符、自动发送附加位、循环发送、发送文件。
- 附加位设置：帧尾结束符、累加和、异或校验、CRC16(Modbus)、CRC16 自定义参数、字节序和校验起始字节。
- 循环发送，可设置毫秒间隔。
- 收发日志、清空接收、复制日志、收发计数复位。
- 历史发送和内置 `{"GetDevStatus":{}}` 快捷填充。
- 应用名和图标使用“网络调试助手”。
- V2.0.0 起采用三页结构：连接设置、收发设置、通信。
- 通信日志支持滚动显示，日志内容写入临时缓存文件，最大保留 100MB，退出 App 后自动清空。
- 连接设置、收发设置、附加位参数和发送框内容会保存到 App 配置存储，重新打开后自动恢复；连接设置页也提供保存、恢复、清除配置按钮。
- 后续每次功能更新都会递增版本号。
- V2.0.2 更换为原创网络通信风格图标，避免继续使用已注册图标。

## Android 工程

源码位置：

```text
app/
```

用 Android Studio 打开项目根目录：

```text
C:\Users\Administrator\Desktop\K16-phone
```

等待 Gradle 同步完成后，连接手机运行即可。

## 默认参数

- TCP Server 监听 IP：`0.0.0.0`
- 远端 IP：`192.168.2.100`
- 端口：`8866`
- 循环发送间隔：`1000 ms`

## 手机做服务端时的 IP

如果开发板作为 TCP Client，配置的服务端 IP 是 `192.168.2.100`，那么手机必须真实拥有这个 IP。

App 里可以选择或手动输入“本地主机地址”，但普通 Android App 不能直接修改手机 WiFi 的 IP 地址。需要在手机系统的 WiFi 高级设置里把手机静态 IP 设置为 `192.168.2.100`，或者把开发板客户端的服务端 IP 改成手机当前显示的 WiFi IP。

## 说明

项目已经使用 Android Gradle Plugin：

```gradle
id "com.android.application" version "8.5.2"
```

当前实现不依赖第三方 Android 网络库，核心收发使用系统 `Socket`、`ServerSocket` 和 `DatagramSocket`。
